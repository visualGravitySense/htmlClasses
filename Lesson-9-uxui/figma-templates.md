# 📐 Шаблоны и чек-листы для Figma заданий

## 🎨 Готовые шаблоны для копирования

### 📋 Шаблон A/B тест гипотезы

```
🧪 A/B ТЕСТ: [Название элемента]

📊 ГИПОТЕЗА:
Если мы изменим [элемент интерфейса] 
с "[текущая версия]" на "[новая версия с историей]",
то [метрика] изменится на [X]%,
потому что [обоснование через психологию пользователя]

🎯 МЕТРИКИ:
• Основная: [главная метрика для измерения]
• Дополнительные: [2-3 дополнительные метрики]

⏱️ ПЛАН ТЕСТА:
• Размер выборки: [количество пользователей]
• Длительность: [количество дней/недель]
• Распределение: 50/50 или 90/10

✅ КРИТЕРИИ УСПЕХА:
• Статистическая значимость: 95%+
• Практическая значимость: +[X]%
• Отсутствие негативного влияния на другие метрики
```

### 🎭 Шаблон персоны для сторителлинга

```
👤 ПЕРСОНА: [Имя, возраст, профессия]

📖 ЕЕ ИСТОРИЯ:
"[Краткое описание жизненной ситуации и контекста]"

🎯 ЦЕЛИ:
• [Основная цель]
• [Дополнительная цель]
• [Эмоциональная потребность]

😰 БОЛИ И СТРАХИ:
• [Основная проблема]
• [Страх или беспокойство]
• [Препятствие к достижению цели]

💡 ИНСАЙТ:
"[Ключевое понимание того, что на самом деле покупает персона]"

🎬 ИСТОРИЯ ТРАНСФОРМАЦИИ:
Было: [текущее состояние]
Стало: [желаемое состояние]
Эмоция: [что чувствует после решения проблемы]
```

### 📱 Шаблон экрана для A/B теста

```
📱 ЭКРАН: [Название экрана]

🅰️ ВЕРСИЯ A (Контрольная):
• Заголовок: "[функциональный заголовок]"
• Описание: "[описание функций]"
• CTA: "[стандартная кнопка]"
• Фокус: Функциональность

🅱️ ВЕРСИЯ B (Сторителлинг):
• Заголовок: "[эмоциональный заголовок]"
• Описание: "[история или результат]"
• CTA: "[эмоциональная кнопка]"
• Фокус: Эмоции и результат

📊 ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Версия B покажет +[X]% по метрике [название метрики]
```

## ✅ Чек-листы для проверки заданий

### 🎨 Чек-лист дизайна

#### **Визуальная привлекательность:**
- [ ] Использована консистентная цветовая схема
- [ ] Типографика читаема и иерархична
- [ ] Достаточно белого пространства
- [ ] Изображения высокого качества
- [ ] Иконки в едином стиле

#### **Дизайн-система:**
- [ ] Созданы переиспользуемые компоненты
- [ ] Использованы стили для текста
- [ ] Консистентные отступы и размеры
- [ ] Единая сетка для всех экранов
- [ ] Цветовая палитра определена

#### **Адаптивность:**
- [ ] Дизайн работает на Desktop (1440px)
- [ ] Адаптирован для планшетов (768px)
- [ ] Мобильная версия (393px)
- [ ] Контент корректно масштабируется
- [ ] Кнопки достаточного размера для тача

### 🎭 Чек-лист сторителлинга

#### **Структура истории:**
- [ ] Определен герой (пользователь)
- [ ] Ясна цель героя
- [ ] Показано препятствие
- [ ] Предложено решение
- [ ] Видна трансформация
- [ ] Вызывает эмоции

#### **Применение в интерфейсе:**
- [ ] Заголовки фокусируются на пользователе
- [ ] Описания показывают результат, не функции
- [ ] CTA кнопки мотивируют к действию
- [ ] Микрокопирайтинг поддерживает нарратив
- [ ] Визуалы усиливают историю

#### **Эмоциональная связь:**
- [ ] Контент вызывает эмоции
- [ ] Пользователь видит себя в истории
- [ ] Понятна ценность для пользователя
- [ ] Создается доверие
- [ ] Мотивирует к действию

### 🧪 Чек-лист A/B тестирования

#### **Гипотеза:**
- [ ] Четко сформулирована
- [ ] Содержит числовой прогноз
- [ ] Основана на психологии пользователя
- [ ] Тестирует одну переменную
- [ ] Измерима

#### **Дизайн теста:**
- [ ] Версии A и B четко различаются
- [ ] Контролируется только одна переменная
- [ ] Обе версии технически реализуемы
- [ ] Учтены все состояния интерфейса
- [ ] Готовы для разработки

#### **Метрики:**
- [ ] Определена основная метрика
- [ ] Выбраны дополнительные метрики
- [ ] Метрики измеримы
- [ ] Учтено влияние на другие показатели
- [ ] Определены критерии успеха

### 📱 Чек-лист UX

#### **Удобство использования:**
- [ ] Интуитивная навигация
- [ ] Логичная последовательность действий
- [ ] Понятные подписи и инструкции
- [ ] Обратная связь на действия пользователя
- [ ] Возможность исправить ошибки

#### **Доступность:**
- [ ] Достаточный контраст текста
- [ ] Размер шрифта не менее 16px
- [ ] Кнопки не менее 44px
- [ ] Альтернативный текст для изображений
- [ ] Логичный порядок табуляции

#### **Производительность:**
- [ ] Быстрая загрузка контента
- [ ] Оптимизированные изображения
- [ ] Минимум шагов до цели
- [ ] Предзагрузка критичного контента
- [ ] Офлайн состояния

## 🔧 Технические требования

### 📐 Размеры экранов:
- **Desktop:** 1440x1024px (основной)
- **Tablet:** 768x1024px
- **Mobile:** 393x852px (iPhone 14 Pro)
- **Email:** 600x800px

### 🎨 Цветовые схемы:

#### **Версия A (функциональная):**
```
Primary: #6C757D (серый)
Secondary: #F8F9FA (светло-серый)
Accent: #007BFF (синий)
Text: #212529 (темно-серый)
Background: #FFFFFF (белый)
```

#### **Версия B (эмоциональная):**
```
Primary: #FF6B6B (коралловый)
Secondary: #FFF8E1 (кремовый)
Accent: #4ECDC4 (мятный)
Text: #2C3E50 (темно-синий)
Background: #FFFEF7 (теплый белый)
```

### 📝 Типографика:
- **H1:** 48px, Bold
- **H2:** 36px, Semibold
- **H3:** 24px, Medium
- **Body:** 16px, Regular
- **Caption:** 14px, Regular

### 🎯 Компоненты:
- **Кнопки:** 48px высота, 16px padding
- **Карточки:** 8px border-radius, тень
- **Поля ввода:** 44px высота
- **Иконки:** 24px или 32px

## 📊 Шаблон презентации результатов

### 🎨 Структура презентации (10-15 слайдов):

1. **Титульный слайд**
   - Название проекта
   - Ваше имя
   - Дата

2. **Проблема**
   - Описание проблемы пользователя
   - Текущее решение
   - Почему нужен A/B тест

3. **Персона**
   - Описание целевого пользователя
   - Его цели и боли
   - Инсайт

4. **Гипотеза**
   - Четкая формулировка
   - Ожидаемые результаты
   - Обоснование

5. **Дизайн A**
   - Скриншот версии A
   - Описание подхода
   - Фокус на функциональности

6. **Дизайн B**
   - Скриншот версии B
   - Описание сторителлинга
   - Фокус на эмоциях

7. **Ключевые различия**
   - Сравнение версий
   - Элементы сторителлинга
   - Ожидаемое влияние

8. **План тестирования**
   - Метрики
   - Размер выборки
   - Длительность

9. **Ожидаемые результаты**
   - Прогноз по метрикам
   - Влияние на бизнес
   - Риски

10. **Выводы**
    - Ключевые инсайты
    - Планы по внедрению
    - Следующие шаги
