Что такое UX?

User Experience (UX)

Пользовательский опыт — это общее впечатление, которое получает пользователь при взаимодействии с продуктом, системой или услугой.

Ключевые принципы UX:

  • Полезность — продукт решает реальные проблемы пользователей
  • Удобство использования — интерфейс интуитивно понятен
  • Доступность — продукт доступен для всех категорий пользователей
  • Желательность — дизайн вызывает положительные эмоции
  • Ценность — продукт приносит пользу бизнесу и пользователям

User Flow

User Flow — это схема, показывающая путь, который проходит пользователь для достижения конкретной цели в продукте.

Основные элементы User Flow:

  • Точка входа — откуда пользователь начинает взаимодействие
  • Действия пользователя — что делает пользователь на каждом этапе
  • Точки принятия решений — где пользователь выбирает дальнейший путь
  • Конечная цель — результат, которого хочет достичь пользователь
  • Альтернативные пути — варианты действий при ошибках или изменении намерений

📋 Практическое задание в Figma #4

Создание User Flow диаграммы

Задача: Построить детальный пользовательский поток

Инструменты: Shapes, Connector plugin, Text, Color styles

Шаги выполнения:

  • Создайте разные формы для разных элементов: овалы (старт/финиш), прямоугольники (действия), ромбы (решения)
  • Используйте плагин "Autoflow" или рисуйте стрелки вручную (Line tool)
  • Создайте Color styles для разных типов элементов
  • Добавьте подписи к каждому элементу
  • Используйте слои (Layers panel) для организации элементов

Основы Design System

Design System — это набор стандартов, компонентов и руководящих принципов, которые обеспечивают согласованность дизайна во всех продуктах.

🎨 Основы

Цвета, типографика, сетки, иконки

🧩 Компоненты

Кнопки, формы, карточки, навигация

📝 Паттерны

Повторяющиеся решения для частых задач

📖 Руководящие принципы

Правила использования и best practices

Преимущества Design System:

  • Согласованность — единообразный опыт пользователей
  • Эффективность — быстрая разработка и прототипирование
  • Масштабируемость — легкое добавление новых функций
  • Коммуникация — общий язык между командами
