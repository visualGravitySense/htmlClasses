Что такое дизайн-система?

Определение

Дизайн-система — это набор переиспользуемых компонентов, стандартов и принципов, которые обеспечивают консистентность в дизайне продукта

Отличия от других инструментов:

UI Kit

Набор готовых элементов интерфейса без правил использования

Style Guide

Документ с визуальными стандартами бренда

Design System

Живая система с компонентами, токенами, принципами и процессами

Примеры успешных систем: Material Design (Google), Human Interface Guidelines (Apple), Carbon (IBM), Polaris (Shopify)

Зачем нужны дизайн-системы?

🎯 Консистентность

Единообразный пользовательский опыт на всех платформах и продуктах

⚡ Скорость

Ускорение процесса дизайна и разработки в 3-5 раз

📈 Масштабируемость

Легкое добавление новых продуктов и функций

🤝 Командная работа

Единый язык между дизайнерами и разработчиками

💰 Экономия

Снижение технического долга и затрат на поддержку

✅ Качество

Меньше ошибок, лучше accessibility и UX

Статистика

Компании с внедренными дизайн-системами экономят до 40% времени на создание новых интерфейсов

Практическое задание 1

Анализ существующих дизайн-систем

Пошаговая инструкция в Figma:

  1. Создание файла: Нажмите "+" → "Design File" → назовите "Анализ дизайн-систем"
  2. Подготовка фреймов: Нажмите F → создайте 3 фрейма размером 1200x800px каждый
  3. Именование: Переименуйте фреймы: "Material Design", "Apple HIG", "IBM Carbon"
  4. Исследование: Откройте в новых вкладках:
    • material.io/design
    • developer.apple.com/design
    • carbondesignsystem.com
  5. Создание секций: В каждом фрейме создайте прямоугольники для разделов
  6. Добавление текста: Нажмите T → добавьте заголовки и описания
  7. Цвета: Создайте цветовые палитры, используя Rectangle (R) + Fill
  8. Типографика: Продемонстрируйте шрифтовые иерархии
  9. Скриншоты: Добавьте примеры компонентов (копируйте изображения)
  10. Выводы: Создайте сравнительную таблицу внизу
Время выполнения: 25 минут. Результат: Понимание различных подходов к построению дизайн-систем

Что такое дизайн-токены?

Определение

Дизайн-токены — именованные сущности, которые хранят визуальные свойства дизайна как единый источник правды (Single Source of Truth)

Типы дизайн-токенов

🔹 Глобальные (Primitive)

Базовые значения:

color-blue-500: #3B82F6
size-4: 16px
font-family-sans: 'Inter'

🔸 Алиас (Semantic)

Семантические роли:

color-primary: {color-blue-500}
color-text-primary: {color-gray-900}
spacing-medium: {size-4}

🔶 Компонентные

Для конкретных компонентов:

button-primary-bg: {color-primary}
card-padding: {spacing-medium}
input-border: {color-gray-300}

Иерархия токенов

Глобальные → Алиас → Компонентные

Изменение глобального токена автоматически обновляет все связанные элементы

Принцип именования: category-property-variant-state
Пример: color-background-primary-hover

Практическое задание 2

Создание базовых дизайн-токенов

Создание файла и структуры:

  1. Новый файл: Создайте файл "Дизайн-токены"
  2. Страницы: Создайте страницы: "Colors", "Typography", "Spacing", "Documentation"
  3. Фреймы: На каждой странице создайте фрейм 1400x1000px

Создание цветовой палитры:

  1. Основные цвета: Создайте 5 квадратов 100x100px для Primary, Secondary, Success, Warning, Error
  2. Оттенки: Для каждого цвета создайте 9 квадратов 60x60px (50, 100, 200...900)
  3. Именование: Переименуйте слои: "Primary/500", "Primary/600" и т.д.
  4. Стили: Создайте Color Styles (4 точки → Create Style)
  5. Нейтральные: Создайте grayscale от white до black (9 оттенков)
  6. Организация: Сгруппируйте цвета в папки по категориям

Типографическая система:

  1. Шрифты: Выберите 2 шрифта (заголовки + основной текст)
  2. Масштаб: Создайте текстовые блоки: H1(32px), H2(24px), H3(20px), H4(18px), Body(16px), Caption(12px)
  3. Параметры: Установите line-height: 1.2 для заголовков, 1.5 для текста
  4. Text Styles: Создайте стили для каждого размера

Задание 2 (продолжение)

Система отступов:

  1. Модульная сетка: Создайте прямоугольники для значений: 4, 8, 12, 16, 24, 32, 48, 64, 96px
  2. Визуализация: Сделайте высоту прямоугольников равной значению отступа
  3. Подписи: Добавьте названия: xs, sm, md, lg, xl, 2xl, 3xl, 4xl, 5xl
  4. Примеры: Покажите применение в компонентах

Документация:

  1. Заголовки: Создайте заголовки разделов
  2. Описания: Добавьте правила использования каждого токена
  3. Примеры: Покажите правильное и неправильное применение
  4. Таблицы: Создайте таблицы с именами токенов и значениями
Время: 25 минут. Горячие клавиши: R (прямоугольник), T (текст), Ctrl+G (группировка), F (фрейм)

Принципы создания компонентов

Atomic Design методология

Атомы → Молекулы → Организмы → Шаблоны → Страницы

⚛️ Атомы

Базовые элементы: кнопки, поля ввода, иконки

🧬 Молекулы

Группы атомов: поисковая строка, карточка продукта

🦠 Организмы

Комплексные секции: хедер, футер, форма

Ключевые принципы:

♻️ Переиспользуемость

Один компонент - множество контекстов использования

🔧 Композиция

Сложные компоненты состоят из простых

📱 Адаптивность

Компоненты работают на всех устройствах

Анатомия компонента в Figma

🎛️ Properties (Пропсы)

Настраиваемые параметры компонента

  • Boolean (вкл/выкл)
  • Instance Swap (замена элементов)
  • Text (текстовые значения)
  • Variant (выбор варианта)

🎨 Variants (Варианты)

Различные версии одного компонента

  • Size: Small, Medium, Large
  • Type: Primary, Secondary, Outline
  • State: Default, Hover, Disabled

🔄 States (Состояния)

Интерактивные состояния

  • Default (по умолчанию)
  • Hover (наведение)
  • Active (нажатие)
  • Disabled (отключено)
  • Focus (фокус)

📐 Auto Layout

Автоматическое позиционирование

  • Direction (направление)
  • Spacing (отступы)
  • Padding (внутренние отступы)
  • Resizing (изменение размера)
Совет: Начинайте с самого простого состояния компонента, затем добавляйте варианты и состояния постепенно

Практическое задание 3 (Часть 1)

Создание атомарных компонентов

Создание кнопки (Button):

  1. Базовая форма: Создайте прямоугольник 120x40px с border-radius 8px
  2. Текст: Добавьте текст "Button" внутрь, выровняйте по центру
  3. Auto Layout: Выделите оба элемента → Shift+A → настройте padding 12px horizontal, 8px vertical
  4. Стили: Примените цвет из ваших токенов (Primary-500)
  5. Компонент: Выделите → Ctrl+Alt+K → назовите "Button"
  6. Варианты: Дублируйте (Ctrl+D) → измените цвета → выделите все → объедините в варианты
  7. Properties: Настройте свойства:
    • Type: Primary, Secondary, Outline, Ghost
    • Size: Small (32px), Medium (40px), Large (48px)
    • State: Default, Hover, Disabled

Создание поля ввода (Input):

  1. Контейнер: Прямоугольник 240x40px, border 1px, radius 6px
  2. Текст: Добавьте placeholder "Enter text..."
  3. Auto Layout: Настройте padding 12px
  4. Состояния: Default, Focus (синяя граница), Error (красная граница), Disabled
  5. Компонент: Создайте компонент с вариантами состояний
Горячие клавиши: Ctrl+Alt+K (создать компонент), Shift+A (Auto Layout), Alt+Drag (дублировать)

Задание 3 (Часть 2)

Молекулярные и организменные компоненты

Создание карточки (Card):

  1. Основа: Прямоугольник 280x320px, radius 12px, тень
  2. Изображение: Добавьте placeholder 280x160px вверху
  3. Контент: Добавьте заголовок, описание, цену
  4. Кнопка: Вставьте созданный ранее компонент Button
  5. Auto Layout: Настройте вертикальный Auto Layout с отступами
  6. Варианты: Создайте варианты с/без изображения, разные размеры

Создание навигации (Header):

  1. Контейнер: Прямоугольник во всю ширину (1200px) высотой 64px
  2. Логотип: Добавьте текст или изображение логотипа слева
  3. Меню: Создайте горизонтальный список ссылок по центру
  4. Действия: Добавьте кнопки справа (Login, Sign Up)
  5. Auto Layout: Настройте горизонтальный Auto Layout
  6. Адаптивность: Настройте Constraints для растягивания

Создание формы:

  1. Контейнер: Создайте фрейм для формы
  2. Поля: Добавьте несколько Input компонентов
  3. Лейблы: Добавьте подписи к каждому полю
  4. Кнопки: Добавьте кнопки Submit и Cancel
  5. Компоновка: Используйте Auto Layout для вертикального размещения

Организация системы

    • Версия и дата обновления

    • Контакты команды
  3. Навигация: Создайте оглавление с ссылками на страницы
  4. Страницы: Создайте страницы для каждой категории

  1. Цвета: Разместите все цветовые токены с кодами
  2. Типографика: Покажите все текстовые стили
  3. Отступы: Визуализируйте систему spacing
  4. Сетка: Опишите принципы grid system
  5. Иконки: Разместите библиотеку иконок

Changelog и гайдлайны:

  1. История изменений: Создайте таблицу с версиями
  2. Quick Start: Пошаговое руководство для новичков
  3. Contribution: Процесс предложения изменений
  4. Support: Контакты для помощи

Практическое задание 5

Подготовка к передаче разработчикам

Включение Dev Mode:

  1. Активация: Нажмите кнопку "Dev Mode" в правом верхнем углу
  2. Выбор компонента: Кликните на любой компонент
  3. Инспектор: Изучите панель справа с CSS свойствами
  4. Копирование: Скопируйте CSS код для разработчика

Создание спецификаций:

  1. Аннотации: Добавьте заметки для разработчиков (комментарии)
  2. Состояния: Убедитесь, что все состояния компонентов видны
  3. Измерения: Проверьте правильность отступов и размеров
  4. Экспорт: Подготовьте иконки и изображения для экспорта

Checklist передачи:

  1. ✅ Токены: Все значения соответствуют design tokens
  2. ✅ Состояния: Все интерактивные состояния описаны
  3. ✅ Responsive: Поведение на разных экранах определено
  4. ✅ Accessibility: Контрастность, focus states, ARIA labels
  5. ✅ Анимации: Transitions и micro-interactions описаны
  6. ✅ Документация: Правила использования компонентов
