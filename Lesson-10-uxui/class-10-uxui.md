# Курс: Дизайн-системы и дизайн-токены для UX/UI дизайнеров

_Продолжительность: 3 часа_

## Структура курса

### Модуль 1: Введение в дизайн-системы (45 минут)

#### Теория (20 минут)

**Что такое дизайн-система?**

- Определение: набор переиспользуемых компонентов, стандартов и принципов, которые обеспечивают консистентность в дизайне продукта
- Отличие от UI Kit и Style Guide
- Примеры успешных дизайн-систем: Material Design, Human Interface Guidelines, Ant Design

**Зачем нужны дизайн-системы?**

- Консистентность пользовательского опыта
- Ускорение процесса дизайна и разработки
- Масштабируемость
- Упрощение командной работы
- Снижение технического долга

**Компоненты дизайн-системы:**

- Принципы дизайна
- Дизайн-токены
- UI компоненты
- Паттерны взаимодействия
- Документация
- Инструменты и процессы

#### Практическое задание 1 (25 минут)

**Анализ существующих дизайн-систем**

_Задание:_

1. Откройте Figma и создайте новый файл "Анализ дизайн-систем"
2. Исследуйте 3 популярные дизайн-системы:
    - Material Design (Google)
    - Human Interface Guidelines (Apple)
    - Carbon Design System (IBM)
3. Для каждой системы создайте фрейм и зафиксируйте:
    - Основные принципы
    - Цветовую палитру
    - Типографику
    - Ключевые компоненты
4. Сравните подходы и выделите общие паттерны

_Результат:_ Понимание различных подходов к построению дизайн-систем

### Модуль 2: Дизайн-токены - основа системы (50 минут)

#### Теория (25 минут)

**Что такое дизайн-токены?**

- Определение: именованные сущности, которые хранят визуальные свойства дизайна
- Принцип "single source of truth"
- Связь между дизайном и кодом

**Типы дизайн-токенов:**

1. **Глобальные токены (Global/Primitive tokens)**
    
    - Базовые значения цветов: `color-blue-500: #3B82F6`
    - Размеры: `size-4: 16px`
    - Шрифты: `font-family-sans: 'Inter'`
2. **Алиас токены (Alias/Semantic tokens)**
    
    - Семантические названия: `color-primary: {color-blue-500}`
    - Роли в интерфейсе: `color-text-primary: {color-gray-900}`
3. **Компонентные токены (Component tokens)**
    
    - Специфичные для компонентов: `button-primary-bg: {color-primary}`

**Категории токенов:**

- Цвета (Colors)
- Типографика (Typography)
- Отступы (Spacing)
- Размеры (Sizing)
- Границы (Borders)
- Тени (Shadows)
- Анимации (Motion)

**Именование токенов:**

- Принципы нейминга
- Структура: `category-property-variant-state`
- Примеры: `color-background-primary`, `spacing-margin-large`

#### Практическое задание 2 (25 минут)

**Создание базовых дизайн-токенов**

_Задание:_

1. Создайте новый файл "Дизайн-токены" в Figma
2. Создайте следующие токены:

**Цвета:**

- Создайте палитру из 5 основных цветов (Primary, Secondary, Success, Warning, Error)
- Для каждого цвета создайте 9 оттенков (50, 100, 200, 300, 400, 500, 600, 700, 800, 900)
- Добавьте нейтральную палитру (Grayscale)

**Типографика:**

- Определите 2 шрифтовые пары
- Создайте типографическую шкалу: H1, H2, H3, H4, Body, Caption
- Укажите размеры, межстрочные интервалы, насыщенность

**Отступы:**

- Создайте модульную сетку отступов: 4, 8, 12, 16, 24, 32, 48, 64, 96px
- Назовите их: xs, sm, md, lg, xl, 2xl, 3xl, 4xl, 5xl

3. Организуйте токены в логические группы
4. Создайте документацию с примерами использования

_Результат:_ Базовый набор дизайн-токенов для дальнейшей работы

### Модуль 3: Построение компонентной библиотеки (60 минут)

#### Теория (15 минут)

**Принципы создания компонентов:**

- Atomic Design методология
- Переиспользуемость
- Композиция vs наследование
- Состояния и варианты

**Анатомия компонента:**

- Properties (пропсы)
- Variants (варианты)
- States (состояния)
- Auto Layout
- Constraints

**Документирование компонентов:**

- Описание назначения
- Правила использования
- Do's and Don'ts
- Интерактивные примеры

#### Практическое задание 3 (45 минут)

**Создание компонентной библиотеки**

_Задание:_

1. Создайте новый файл "Компонентная библиотека"
2. Используя созданные дизайн-токены, создайте следующие компоненты:

**Атомарные компоненты:**

- Button (Primary, Secondary, Outline, Ghost варианты + состояния)
- Input Field (Default, Error, Disabled состояния)
- Checkbox и Radio Button
- Icon (создайте набор из 20 иконок)

**Молекулярные компоненты:**

- Search Bar
- Card
- Navigation Item
- Form Field (Label + Input + Help Text)

**Организменные компоненты:**

- Header/Navigation
- Footer
- Form
- Product Card Grid

3. For each component:
    
    - Настройте Auto Layout
    - Создайте варианты (Variants)
    - Добавьте интерактивные состояния
    - Используйте дизайн-токены
    - Добавьте описание и правила использования
4. Создайте систему именования компонентов
    
5. Организуйте компоненты в логическую структуру
    

_Результат:_ Функциональная библиотека компонентов с документацией

- Сбор обратной связи
- Эволюция системы

#### Практическое задание 5 (15 минут)

**Подготовка к передаче в разработку**

_Задание:_

1. Откройте Dev Mode в Figma
    
2. Подготовьте спецификации для ваших компонентов:
    
    - Экспортируйте CSS код
    - Проверьте правильность токенов
    - Добавьте аннотации для разработчиков
3. Создайте Design-to-Code checklist:
    
    - Соответствие токенов
    - Поведение компонентов
    - Responsive поведение
    - Accessibility требования

## Домашнее задание

**Создание реальной дизайн-системы для проекта**

1. Выберите существующий проект или придумайте новый продукт
    
2. Примените полученные знания:
    
    - Создайте полный набор дизайн-токенов
    - Разработайте 15-20 компонентов
    - Создайте 3-5 готовых страниц, используя систему
    - Документируйте все решения
3. Подготовьте презентацию своей системы (10 минут)
    

**Критерии оценки:**

- Консистентность использования токенов
- Качество компонентов
- Организация и документация
- Практическая применимость
