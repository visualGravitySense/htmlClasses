Создание базовой дизайн-системы с design tokens в Figma — отличная идея для масштабируемого дизайна. Вот пошаговый план:

## 1. Подготовка структуры

Создай новый файл Figma и организуй страницы:

- **🎨 Design Tokens** — основные токены
- **📦 Components** — компоненты
- **📖 Documentation** — документация
- **🧪 Testing** — тестирование компонентов

## 2. Создание базовых Design Tokens

Начни с этих основных категорий:

**Цвета (Colors)**

- Primary: основной бренд-цвет + оттенки (50, 100, 200...900)
- Secondary: дополнительный цвет
- Neutral: серые оттенки для текста и фонов
- Semantic: success, warning, error, info

**Типографика (Typography)**

- Font families
- Font sizes (12px, 14px, 16px, 18px, 24px, 32px, 48px)
- Line heights (120%, 140%, 160%)
- Font weights (400, 500, 600, 700)

**Spacing (Отступы)**

- 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, 96px

**Border Radius**

- 4px, 8px, 12px, 16px, 24px

## 3. Настройка Variables в Figma

1. Открой Variables panel (справа в панели дизайна)
2. Создай коллекции для каждого типа токенов
3. Добавь переменные с логичными названиями:
    - `color/primary/500`
    - `spacing/medium`
    - `typography/body/large`

## 4. Создание стилей (Styles)

Преобразуй переменные в стили для удобного переиспользования:

- Color styles
- Text styles
- Effect styles (тени, размытие)
