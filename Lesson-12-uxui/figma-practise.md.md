## Создание анимации загрузки

1. **Создайте кнопку:**
    - Нарисуйте прямоугольник с закругленными углами
    - Добавьте градиент (фиолетовый → синий)
    - Добавьте текст "Загрузка..."
2. **Создайте индикатор загрузки:**
    - Нарисуйте круг (например, 16x16px)
    - Сделайте обводку 2px, без заливки
    - Создайте пунктирную обводку или оставьте часть круга прозрачной
    - Разместите слева от текста
3. **Сделайте компонент:**
    - Выделите всю кнопку и создайте компонент (Ctrl+Alt+K)
    - Назовите "Button Loading"
4. **Создайте анимацию вращения:**
    - Скопируйте кнопку (Ctrl+D)
    - Во второй копии поверните индикатор на 90°
    - Создайте еще 2 копии с поворотами на 180° и 270°
5. **Настройте прототип:**
    - Перейдите в режим Prototype
    - Соедините кадры стрелками по кругу (1→2→3→4→1)
    - Для каждого перехода установите:
        - Trigger: "After delay"
        - Delay: 0.2s (200ms)
        - Animation: "Smart animate"
        - Easing: "Linear" (для равномерного вращения)
6. **Альтернативный способ - один кадр:**
    - Создайте только 2 состояния кнопки
    - В первом индикатор повернут на 0°
    - Во втором на 360°
    - Переход: Smart animate, Linear, 1s
    - После завершения анимация зациклится

## Дополнительные эффекты:

- Можете добавить пульсацию тексту
- Изменить непрозрачность индикатора
- Добавить легкое свечение кнопке

Для предварительного просмотра нажмите на иконку Play в правом верхнем углу Figma.

## Анимация при наведении (Hover)

1. **Создайте компонент кнопки:**
    - Выделите вашу кнопку и нажмите Ctrl+Alt+K (Cmd+Opt+K на Mac)
    - Назовите компонент
2. **Добавьте вариант для hover:**
    - В панели свойств компонента нажмите "+" рядом с Properties
    - Выберите "Variant" и назовите его "State"
    - Создайте два состояния: "Default" и "Hover"
3. **Настройте анимацию:**
    - Во вкладке "Prototype" выберите исходное состояние
    - Протяните стрелку к hover-состоянию
    - В настройках взаимодействия выберите:
        - Trigger: "On hover"
        - Action: "Change to"
        - Animation: "Smart animate"
        - Easing: "Ease out" или "Ease in-out"
        - Duration: 200-300ms

## Анимация прокрутки (Scroll)

Если вам нужна анимация, которая срабатывает при прокрутке страницы:

1. **Создайте фреймы:**
    - Основной фрейм с кнопкой в исходном состоянии
    - Второй фрейм с кнопкой в конечном состоянии
2. **Настройте scroll trigger:**
    - Выберите элемент-триггер
    - В Prototype установите:
        - Trigger: "After delay" или используйте плагины для scroll-анимаций
        - Action: "Change to"
        - Destination: конечное состояние кнопки

## Эффекты для кнопки:

- Изменение цвета фона
- Трансформация (масштаб, поворот)
- Изменение тени
- Анимация текста или иконки внутри кнопки

Для более сложных scroll-анимаций рекомендую использовать плагины типа "LottieFiles" или экспортировать анимацию для реализации в коде.
